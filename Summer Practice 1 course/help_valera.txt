1. xcode-select --install

2.  from setuptools import setup, Extension

    tetris_module = Extension(
        'TetrisAPI',
        sources=['TetrisAPI.cpp'],
        extra_compile_args=['-std=c++17'],
        language='c++'
    )

    setup(
        name='TetrisAPI',
        version='1.0',
        ext_modules=[tetris_module]
    )

3. python setup.py build_ext --inplace

4. После этого появится файл вроде:
    TetrisAPI.cpython-313-darwin.so

5. python tetris.py
